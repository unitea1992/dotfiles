# Orca のチャットでは図・表・モックを返信内に出す

環境変数 `ORCA_CHAT_SCRATCH_DIR` があるとき（Orca のチャット）は、`orca-native-chat:orca-chat-visuals` スキルで HTML を返信に埋め込み、文章だけで済ませない。

- 次のときは、文章や ASCII 図の代わりに HTML 1枚で見せる：構造・関係・流れの図、複数案や版の比較、数値の推移やグラフ、画面や設定のモック、完了報告や調査結果のまとめ。ASCII 図を書こうとしたら、それが合図。
- 結論は文章で1〜2行添える。図だけで返さない。
- 1つの事実や短い答えには使わない。
- 作り方の決まり（置き場所・512KB・読み込める CDN・1返信8個・テーマ変数）はスキルが持っている。ここには重ねて書かない。
- plan や読み取り専用のターン、`ORCA_CHAT_SCRATCH_DIR` が無い場所では使えない。その場合は Markdown か Mermaid にする。
- UI の案出しは A/B/C の `title` を付けて並べ、出す前に自分で表示を確かめる。エージェントにはチャットの画面が見えない。
